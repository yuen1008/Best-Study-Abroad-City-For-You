# Best-Study-Abroad-City-For-You
A project just for fun. Chinese version available. AI-powered version requires you to use the [index.html](https://github.com/yuen1008/Best-Study-Abroad-City-For-You/blob/main/index.html) file.

To play with it, you will need to:

(1) download the index.html file ;

(2) Go to the AI you like, apply for a free API ; 

(3) Open the html file with an editor, find line 755 and past the API between the "".

(4) Run it!

If you want to use an AI-free version, please refer to the other file [study_abroad_match.html](https://github.com/yuen1008/Best-Study-Abroad-City-For-You/blob/main/study_abroad_match.html).
